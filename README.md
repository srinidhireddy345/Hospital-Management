# Hospital-Management

## MediConnect Hospital Appointment Management System

A React and Firebase application for managing hospital appointments, doctors, patient profiles, notifications, and health packages.

## Run locally

```bash
npm install
npm run dev
```

Vite prints a local URL and, when available, a network URL. Open the network URL from another device on the same Wi-Fi or LAN. If it is unreachable, allow Node.js through Windows Firewall on a private network.

## Checks

```bash
npm run build
npm run lint
```
